# Flow Language Reference

Moved. The flow language reference is packaged with the authoring skill so it installs alongside
it: [src/llm_browser/skill/reference/FLOWS.md](src/llm_browser/skill/reference/FLOWS.md).

`llm-browser skill install` copies that directory — `reference/FLOWS.md`,
`reference/FLOW_PATTERNS.md` and `reference/DRIVERS.md`, next to `SKILL.md` — into
`.claude/skills/llm-browser-flows/` of the target repo. The files under `docs/` with these names
are pointers like this one, and are not what gets installed.
